# 📝 Modern Not Defteri (Notepad App)

React, TypeScript ve Tailwind CSS kullanılarak geliştirilmiş, modern, kullanıcı dostu ve özellik açısından zengin bir not alma uygulaması.

![Project Status](https://img.shields.io/badge/status-active-success.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

## 🚀 Özellikler

*   **📝 Not Yönetimi:** Kolayca not oluşturun, düzenleyin ve silin.
*   **📂 Kategori Sistemi:** Notlarınızı renk kodlu kategorilerle organize edin.
*   **🔍 Gelişmiş Arama:** Başlık ve içerik içinde anlık arama yapın.
*   **🎨 Tema Desteği:** Göz yormayan Karanlık (Dark) ve Açık (Light) mod seçenekleri.
*   **🌍 Çoklu Dil:** Türkçe (TR) ve İngilizce (EN) dil desteği.
*   **⭐ Favoriler:** Önemli notlarınızı favorilere ekleyerek hızlıca erişin.
*   **🏷️ Etiketleme:** Notlarınıza #etiket ekleyerek daha detaylı gruplandırma yapın.
*   **💾 Yerel Kayıt:** Verileriniz tarayıcınızda (LocalStorage) güvenle saklanır.

## 🛠️ Teknolojiler

Bu proje aşağıdaki modern teknolojiler kullanılarak geliştirilmiştir:

*   [React](https://reactjs.org/) - UI Kütüphanesi
*   [TypeScript](https://www.typescriptlang.org/) - Tip Güvenliği
*   [Vite](https://vitejs.dev/) - Hızlı Geliştirme Ortamı
*   [Tailwind CSS](https://tailwindcss.com/) - Styling
*   [Lucide React](https://lucide.dev/) - İkon Seti
*   [Date-fns](https://date-fns.org/) - Tarih İşlemleri

## 📦 Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1.  Depoyu klonlayın:
    ```bash
    git clone https://github.com/KULLANICI_ADINIZ/notepad-app.git
    ```
2.  Proje dizinine gidin:
    ```bash
    cd notepad-app
    ```
3.  Bağımlılıkları yükleyin:
    ```bash
    npm install
    ```
4.  Uygulamayı başlatın:
    ```bash
    npm run dev
    ```
